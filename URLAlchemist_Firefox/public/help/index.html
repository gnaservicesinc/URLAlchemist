URL Alchemist — Overview

URL Alchemist is a Chrome extension for building small browser workflows from visual blocks. It can clean URLs, route selected text or clipboard text, show page overlays, fetch remote data, play media, log runs, and redirect tabs when a compiled Action Pack produces a new URL.

The extension is local-first. Workspaces, Action Packs, logs, large resources, and settings live in extension storage unless you export a file, restore a backup, or opt into Google Sync for small non-resource items.

Key Concepts

Workspaces

A workspace (file extension .workspace) is the editable source document where you design behavior with blocks and connections. Workspaces store metadata, trigger settings, the saved canvas viewport, and the full source graph.

Action Packs

An Action Pack (file extension .actionpack) is the compiled binary runtime form of a workspace. Action Packs are compact, validated, and include risk metadata so they can be reviewed before installation.

Installed Action Packs also have local-only install metadata for trust state, logging, lock state, install time, and block statistics. That local metadata is not exported in .actionpack files.

The Engine

The background engine listens for navigation, hotkey, context-menu, interval, conditional, and overlay events. When a matching Action Pack is installed and enabled, the engine runs the compiled instruction set with strict instruction, redirect, remote request, and regex budgets.

The editor calls the top-level schedule Run. Run on input data means the pack runs from configured input sources such as URL, selected text, link URL, page title, clipboard, page text, or page metadata. Conditional runs evaluate a background-safe condition workspace with a Condition Out block before running. Keyboard, mouse, and tick events are separate event-handler blocks inside the workspace.

Quick Start

  1. Open the Examples tab and search by task, such as link cleanup, GitHub, clipboard, research, remote requests, break reminders, overlays, or custom blocks.
  2. Click Install Action Pack to try a compiled example, or Open Workspace to inspect and modify the source first.
  3. Use the Workspace Editor to build your own transformations from scratch.
  4. When your workspace is valid, click Build & Install to compile it into an Action Pack and activate it.
  5. Create a Content Blocker workspace when you need page-load decisions, recurring checks, ordered challenge pages, optional locks, or a URL-list blocker.
  6. Use Manage Resources to view logs, export files, update metadata, or delete installed resources.
  7. Use Settings to export a backup before reinstalling Chrome or the extension, or to enable the local Ollama workspace builder.

Built-In Examples To Try

  • Clean Share Link removes common tracking parameters from a URL before you share it.
  • Open GitHub PR Files opens the Files view for a GitHub pull request URL.
  • Search Selected Text turns selected page text into a search URL from a hotkey.
  • Copy Markdown Citation formats the current page title, URL, and local date as a Markdown citation and copies it.
  • Normalize Clipboard Text trims and normalizes copied text before writing the cleaned value back.
  • Research Trail shows the previous and current page together, then remembers the current title and URL for the next run.
  • Redact Emails for Screen Sharing masks visible email addresses after confirmation before a presentation or recording.
  • Fetch and Preview Text fetches HTTPS text and previews it in an overlay without navigating or mutating page text.
  • Confirmed Webhook Test prompts for an HTTPS endpoint, requires confirmation, and sends only a static sample payload—never current page data.
  • 20-20-20 Break Reminder shows a periodic eye-break reminder.
  • Focus Sprint Timer demonstrates a visible real-time overlay timer built from generic event, state, and draw blocks.
  • Normalize Text is editable source for a reusable text-normalization custom block.

Overlay Workflows

Overlay Input opens a temporary overlay and returns a bounded summary of keyboard and mouse events captured while that overlay is open.

For real-time applications, use the event-handler blocks: On Trigger Event, Keyboard In, Mouse In, and Overlay Tick In. Pair them with Overlay Control, Overlay Draw, and shared state blocks to build interactive overlay workflows without custom JavaScript.

The bundled Focus Sprint Timer example demonstrates a practical real-time timer built from those generic workspace blocks.

Import Safety

Imported Action Packs open in the staging gate instead of saving immediately. Review the manifest, risk badges, plain-language steps, and sandbox result before confirming import.

Treat clipboard, raw page, remote request, page mutation, and overlay input behavior as sensitive. URL Alchemist surfaces these risks so you can decide before the pack is installed.

Resources And AI Connectors

Large local images, video, and audio are stored once in IndexedDB and referenced by SHA-256 from workspaces and installed Action Packs. Resources are excluded from browser sync and are bundled only when exporting a workspace, Action Pack, or unlocked backup.

AI workspace instructions are editable in Settings and can be restored to the URL Alchemist default. Custom instructions stay in local extension storage and manual backups; browser sync receives the default instead. The fixed recipe contract, workspace validation, compiler checks, and safety policy are separate from this editable guidance and cannot be overridden by it.

Ollama drafting sends your request, editable workspace instructions, the machine-readable block and port catalog, and an internal recipe for the eligible open graph only to a loopback endpoint such as http://127.0.0.1:11434; redirects and oversized responses are rejected. The returned complete graph must pass recipe, workspace, compiler, compiled Action Pack where applicable, and risk checks. Preview shows derived risk, applicable permissions, sensitive behavior, and the safely rendered complete recipe JSON before Apply. Custom Block permissions are determined later by the host Action Pack. A draft becomes ineligible if the open graph changes, and full replacement clears stale compatibility metadata. Content Blockers and workspaces that depend on embedded assets, local resources, or installed Custom Blocks are rejected rather than converted lossily. Recipe JSON is a build and LLM protocol, not a portable user file type, and Action Packs never call an AI provider at runtime.

Debugging

Manage Resources includes View Log, Export Log, and Clear Log actions for each installed Action Pack. New installs default logging off unless Settings changes the default; migrated existing packs keep logging on. Logs record run timestamps, exit codes, issues, and entries written by Save string to log.

Per-pack logs rotate automatically after the newest 300 entries or about 256 KB, whichever limit is reached first.

Use Abort when a workflow needs to stop mid-run after a boolean guard becomes true. Abort returns exit code 130 and stops later instructions in that run.
