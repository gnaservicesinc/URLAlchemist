Workspaces

A workspace is the editable source document for URL Alchemist. It stores blocks, connections, metadata, Run settings, and the saved canvas viewport.

Editing

Use the Workspace Editor to add blocks, select and move one or more blocks, connect compatible ports, and configure metadata. Edit a block name inline in its card header. When the full Block Library is open, the quick shortcuts are hidden so each block appears once. Start from a bundled example when you want a practical pattern, then save a copy and adjust the blocks. Workspaces can be saved while incomplete, but compiling requires a valid graph and at least one output path.

Logical Flow Branches

Logical Flow is a paired composite with a Logic condition and a Logical Flow controller. Its True and False branch regions are connection-driven guides, not drag-and-drop targets. Connect the controller's True or False output to a block to adopt it into that branch. When a block or downstream subtree is newly adopted, the editor automatically positions it at the start of the chosen branch.

Each branch region expands around blocks that belong exclusively to that branch. A downstream continuation reached by both branches is a shared merge and stays outside both regions. Dragging any connected card in a Logical Flow moves the whole composite live, including its paired core, branch members, and regions. Disconnect a branch block first when you need to reposition it independently.

Run Settings

Run on input data starts a pack when configured inputs arrive, such as URL, selected text, link URL, page title, clipboard, page text, or page metadata. Hotkey, context-menu, interval, conditional, keyboard, mouse, and tick events are separate triggers or event handlers.

Conditional runs use a selected condition workspace with exactly one connected Condition Out block. Version 2.1 evaluates those conditions from browser alarms, supports rising-edge and while-true behavior, and limits the condition VM to background-safe read/transform blocks.

Saving and Recovery

The Save Workspace command writes the current source document into installed workspaces. While editing, URL Alchemist also writes a temporary recovery draft so browser crashes or tab closes do not discard hours of work.

Viewport changes are saved with the workspace so the editor reopens at the same pan and zoom.

Installed Workspaces

The Manage Resources tab lists installed workspaces. You can open, edit metadata, export, compile, or delete a workspace without deleting any compiled Action Pack that came from it.

When a workspace and Action Pack share the same source ID, Manage Resources shows the pairing so you can understand what source produced the runtime pack.

Variables And Substitution

Declared variables appear in the editor side panel. Fields that reference a declared variable change color so usage is visible while you build. Use unescaped names such as $pageTitle to insert a variable. Use \$pageTitle when you want literal text instead of a variable.

Substitution formats strings without writing a regex. Connect values to $1, $2, and later inputs, then type those tokens into the pattern field. A dollar sign followed by a number is reserved for these connector variables.

When a literal field uses a declared variable, the matching input connector is disabled for that field. Use either a connected input or a variable reference, not both.

Select multiple blocks with Shift-click or Shift-drag. Use the canvas toolbar or Ctrl+C/Ctrl+V on Windows and Cmd+C/Cmd+V on macOS to copy and paste selected blocks.

Utility Blocks

Text Transform handles common cleanup such as trimming, whitespace collapse, control-character stripping, case changes, and URL encode/decode. Text Split/Join converts between text and list data by lines, whitespace, comma, or a custom separator.

List literals are edited one string per line. Choose URL List when invalid URL entries should be removed automatically, then use Add string to list or Content Blocker Check list for URL to build URL-list decisions. Check list for URL can return either 1 for challenge or 2 for block when a URL is found.

URL Query parses URL parts, gets or changes parameters, keeps named parameters, sorts parameters, and rebuilds URLs without regex. Dict Operation merges dictionaries, deletes keys, checks keys, and lists keys or values.

Content Blocker Surfaces

Page Load Decision runs once per eligible page load. Recurring Check runs while an allowed page stays open. Both surfaces send 0 to allow, 1 to show the challenge page, or 2 to block.

Challenge Page task blocks run one at a time from left to right, then top to bottom. Put a Timer before a Clicker to require the timer first, then the click task. Challenge Result marks the intended success path; the blocker page grants Continue only after the ordered task list is complete.

Debug Blocks

Save string to log writes a timestamped entry to the current Action Pack log with a severity level. Abort stops the current run when its boolean input is true and returns exit code 130.

Interactive Blocks

Interaction blocks can ask for input, show overlays, play media, capture a bounded input summary, or run event handlers from a URL Alchemist-owned overlay. Keyboard, mouse, and tick event chains share session state with the normal Run chain so a workspace can behave like one small application.

Get Image, Get Video, and Get Audio use an asset byte budget for remote or bundled media. The default is 10 MB and the editor allows up to 50 MB with normal timeout handling.

Use Overlay Control to create the visible overlay session before keyboard, mouse, or tick events can run. Overlay Draw renders reusable grid cells and text into that session. Closing the overlay stops event routing.

Backups

Export a local backup from Settings before uninstalling the extension, changing browsers, or doing release testing. Chrome removes extension local storage when an extension is removed.
