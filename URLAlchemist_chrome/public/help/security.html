Security

URL Alchemist treats imported Action Packs as untrusted bytecode. Validation recomputes risk and permission metadata from the compiled instructions instead of trusting wrapper claims.

Tracing

Tracing records local execution steps and issues for selected installed Action Packs. Use it when testing extended or high-risk packs.

Hardening

Hardening settings can reduce VM instruction count, redirect recursion, and regex timeout limits. They cannot loosen the built-in default safety budgets.

Clipboard, raw page, remote request, and page mutation behavior should be reviewed carefully before installing a pack.

File Audit

The Security tab can inspect an uninstalled workspace or Action Pack and report validation, permissions, risk reasons, trigger plan, and VM instructions without saving it.
