Workspaces

A workspace is the editable source document for URL Alchemist. It stores blocks, connections, metadata, Run settings, and the saved canvas viewport.

Editing

Use the Workspace Editor to add blocks, connect compatible ports, and configure metadata. Workspaces can be saved while incomplete, but compiling requires a valid graph and at least one output path.

Saving and Recovery

The Save Workspace command writes the current source document into installed workspaces. While editing, URL Alchemist also writes a temporary recovery draft so browser crashes or tab closes do not discard hours of work.

Viewport changes are saved with the workspace so the editor reopens at the same pan and zoom.

Installed Workspaces

The Manage Resources tab lists installed workspaces. You can open, edit metadata, export, compile, or delete a workspace without deleting any compiled Action Pack that came from it.

Variables And Substitution

Declared variables appear in the editor side panel. Fields that reference a declared variable change color so usage is visible while you build.

Substitution formats strings without writing a regex. Connect values to $1, $2, and later inputs, then type those tokens into the pattern field. A dollar sign followed by a number is reserved for these connector variables.

Debug Blocks

Save string to log writes a timestamped entry to the current Action Pack log with a severity level. Abort stops the current run when its boolean input is true and returns exit code 130.

Interactive Blocks

Interaction blocks can ask for input, show overlays, play media, capture a bounded input summary, or run event handlers from a URL Alchemist-owned overlay. Keyboard, mouse, and tick event chains share session state with the normal Run chain so a workspace can behave like one small application.

Get Image, Get Video, and Get Audio use an asset byte budget for remote or bundled media. The default is 10 MB and the editor allows up to 50 MB with normal timeout handling.

Use Overlay Control to create the visible overlay session before keyboard, mouse, or tick events can run. Overlay Draw renders reusable grid cells and text into that session. Closing the overlay stops event routing.
