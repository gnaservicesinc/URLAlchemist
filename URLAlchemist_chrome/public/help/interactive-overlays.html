Interactive Overlays

Interactive overlay workspaces use event source blocks instead of a single blocking prompt. On Trigger Event handles the normal workspace Run event. Keyboard In, Mouse In, and Overlay Tick In run only while a URL Alchemist-owned overlay session is active.

Overlay Session

Overlay Control starts, stops, toggles, or checks the visible full-page overlay. The overlay has a white page-covering background and a Close button so control capture is obvious and recoverable.

Overlay Draw redraws a simple grid scene from reusable cell dictionaries such as {"x":8,"y":8,"color":"#16a34a"}. Text input can update the overlay header.

State And Events

Shared State stores values for the active session so Run, keyboard, mouse, and tick handlers can cooperate. Dict Get, List Operation, Condition Select, Random Number, Constant, and Sleep provide general application logic without a game-specific opcode.

Mouse events also populate $mouse_x and $mouse_y. The values are overlay-local while the pointer is inside the overlay and -1 after pointer leave.

Example

The bundled Snake Overlay Arcade workspace is built from these generic blocks. Its hotkey opens or closes the overlay, keyboard events change direction or exit, mouse clicks toggle pause, and tick events move the snake, update shared state, spawn food, and redraw the grid.

Keyboard and mouse events are routed only from the active URL Alchemist overlay session. They do not re-fire the workspace hotkey Run.
