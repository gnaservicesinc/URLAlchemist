URL Alchemist — Overview

URL Alchemist is a browser extension that acts as middleware for URL navigation. It intercepts, transforms, and redirects URLs based on user-defined Action Packs. You build transformation logic visually in a workspace editor, compile it into an optimized Action Pack, and the extension runs that logic on matching pages.

Key Concepts

Workspaces

A workspace (file extension .workspace) is a full-featured visual document where you design URL transformation logic using drag-and-drop blocks and connections. Workspaces are your editable source files. You can have multiple workspaces installed.

Action Packs

An Action Pack (file extension .actionpack) is a compiled, optimized, binary distribution of a workspace. Action Packs are what the extension engine actually executes at runtime. They are compact, validated, and include risk metadata so users can inspect them before installation.

The Engine

The background engine listens for navigation events and, when a matching Action Pack is installed and enabled, runs the compiled instruction set against the URL. Transformed URLs are applied to the tab silently.

The editor calls the top-level schedule Run. On page load means the pack runs from page input data; keyboard, mouse, and overlay events are separate event-handler blocks inside the workspace.

Quick Start

  1. Open the Examples tab to browse built-in Action Packs.
  2. Click Install Action Pack on an example to try it immediately, or Open Workspace to inspect and modify the source.
  3. Use the Workspace Editor to build your own transformations from scratch.
  4. When your workspace is valid, click Build & Install to compile it into an Action Pack and activate it.
  5. Use Export to share your Action Pack as a .actionpack file.

Tab Reference

  • Examples — Browse and install bundled example Action Packs and workspaces.
  • Manage Resources — View, manage, export, and delete installed workspaces and Action Packs.
  • Import — Import workspace or Action Pack files via drag-and-drop or file picker.
  • Workspace Editor — The visual node editor where you build URL transformation logic.
  • Security — Enable tracing, audit files, configure hardening limits, and monitor alerts.
  • Settings — Global toggles, UI scaling, clipboard permissions, and backup/restore.
  • Help — This documentation.
  • About — Version info, license, repository links, and reset options.

Overlay Workflows

Overlay Input opens a temporary overlay and returns a bounded summary of keyboard and mouse events captured while that overlay is open.

For real-time applications, use the event-handler blocks: On Trigger Event, Keyboard In, Mouse In, and Overlay Tick In. Pair them with Overlay Control, Overlay Draw, and shared state blocks to build interactive overlay workflows without custom JavaScript.

The bundled Snake Overlay Arcade example demonstrates a classic arcade game built from those generic workspace blocks.

Debugging

Manage Resources includes View Log and Export Log actions for each installed Action Pack. Logs record run timestamps, exit codes, issues, and entries written by Save string to log.

Use Abort when a workflow needs to stop mid-run after a boolean guard becomes true. Abort returns exit code 130 and stops later instructions in that run.
