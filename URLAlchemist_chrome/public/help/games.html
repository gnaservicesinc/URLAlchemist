Games

URL Alchemist can launch small built-in games from a workspace. The first game block is Arcade Game, which currently supports the Space Defender preset.

How It Works

Add an Arcade Game block, choose the Space Defender preset, and bind the workspace to a trigger such as a hotkey. When the Action Pack runs, URL Alchemist opens an overlay on the current page and runs the built-in game code.

Controls

Space Defender uses arrow keys or mouse movement to move, Space or click to fire, and Escape or Close to exit. The block returns a result record with score, lives, duration, and close reason.

Security

Keyboard and mouse capture only happen while the overlay is open. Imported Action Packs cannot provide their own JavaScript game code; they can only request a known game preset and settings that the import review explains.

Example

The bundled Space Defender Overlay example installs a hotkey-launched game workspace. Use it to verify overlay launch, keyboard capture, mouse capture, close behavior, and score storage.
