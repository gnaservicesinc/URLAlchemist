Action Packs

An Action Pack is the compiled binary runtime form of a workspace. The extension executes Action Packs, not workspace source files.

Compilation

Compilation validates required connections, block compatibility, regex safety, risk metadata, permissions, and trigger details. A valid workspace can be compiled and exported from the editor or Manage Resources.

Import Review

Imported Action Packs open in the staging gate. The gate shows metadata, risk warnings, a visual instruction summary, and an interactive sandbox before the Confirm Import button unlocks.

Pairing

Manage Resources draws a connection between an installed workspace and any installed Action Pack compiled from it. You may delete either resource independently.
