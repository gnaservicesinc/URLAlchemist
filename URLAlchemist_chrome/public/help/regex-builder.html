Regex Builder

The regex builder helps create transformation patterns from sample text. It is designed for users who do not want to write manual regular expressions first.

Visual Mode

Paste a sample URL or text value, select the part you want to match, and tune generated tokens. The builder stores both the visual token model and the generated pattern in the workspace.

Advanced Mode

Advanced Mode enables manual regex editing. Patterns are still validated and run through the same safety wrappers used by compiled Action Packs.

Replacement Tokens

Payloads can use safe replacement tokens such as regex capture groups, {date}, and clipboard placeholders when the pack requests the relevant permission.

The Substitution block is the simpler string formatter. Connect values to $1, $2, and later inputs, then reference those tokens in the pattern field. Declared variables use names like $pageTitle; numeric names such as $1 are reserved for substitution connectors. Escape a dollar sign as \$pageTitle when you want literal text instead of a variable.

When To Use Each Tool

Use a regex block when you need pattern matching, capture groups, or URL cleanup. Use Substitution when you only need to assemble a string from connected values.
