# URL Alchemist 2.8.0

Create and maintain browser workflows in a redesigned workspace studio.

- Start from Workspaces, search saved projects, resume drafts, or choose a browser workflow, Content Blocker, or reusable block.
- Move through Configure, Build flow, and Test & review with persistent save/build controls and clear readiness feedback.
- Find blocks by name or type, fit the canvas, arrange event lanes, and jump from validation issues to the relevant graph surface.
- Keep context alongside a connected string in Save string to log. Use `Visited: {value}` for inline formatting, or a message prefix to append the input. Connected data stays literal.
- Build and publish GitHub release artifacts automatically, with independent Chrome Web Store and Firefox AMO submission jobs and Firefox reviewer source upload.

Portable workspace and Action Pack formats, legacy V1 import, and existing compiled log behavior remain compatible. Store submissions require repository credentials and remain subject to each store's review process.
